# はじめかた（JUGEM 用）

やることは **2つだけ** です。1回終われば、あとは「リンクを貼る」だけになります。

---

## 1. サイトを公開する（1回だけ・5分）

1. GitHub でこのリポジトリを開く
2. 上のタブ **Settings** → 左メニュー **Pages**
3. **Source** を `GitHub Actions` にする
4. 数分待つと `https://<オーナー名>.github.io/<リポジトリ名>/` で公開されます

これが **お客様用URL** です。誰でも無料で見られます。

---

## 2. 更新できるようにする（1回だけ・5分）

更新ページは公開URLの後ろに `admin/` を付けたアドレスです。

```
https://<オーナー名>.github.io/<リポジトリ名>/admin/
```

ここを **本人専用URL** としてブックマークしてください。

### なぜ「本人専用」なのか

このページは開けても、**GitHub のトークンを入れた端末からしか更新できません**。
トークンはブラウザの中だけに保存され、公開サイトには一切含まれません。
他の人が開いても、閲覧すらできても、書き込みは一切できません。

### トークンの作り方

1. [Fine-grained personal access token の作成ページ](https://github.com/settings/personal-access-tokens/new) を開く
2. **Repository access** → `Only select repositories` → このリポジトリを選ぶ
3. **Permissions** → **Repository permissions** → **Contents** を **Read and write** にする
4. **Generate token** を押して、出てきた `github_pat_…` をコピー
5. 更新ページの「接続設定」に、オーナー名・リポジトリ名・ブランチ（`main`）・トークンを貼って「接続する」

> 権限は Contents だけで十分です。それ以外は付けないでください。
> 有効期限を設定した場合は、切れたら同じ手順で作り直してください。

---

## 毎回の使いかた

1. 更新ページを開く
2. 一番上の箱に **リンクを貼る**
3. 「追加する」を押す — タイトルもサムネイルも自動で入ります
4. 必要ならその場で文字を直す
5. 右下の **公開する** を押す

1〜2分で公開サイトに反映されます。

### 貼るリンクの行き先は自動で決まります

| 貼ったもの | 入る場所 |
|---|---|
| YouTube | 実績 |
| X / Instagram / TikTok | ファンの声 |
| Amazon / 楽天 / Apple | 愛用品 |
| それ以外（記事など） | 最新情報 |

違う場所に入っても、削除してタブを変えて貼り直せば大丈夫です。

---

## アクセス数を見る（任意）

「アクセス」タブから設定します。無料でおすすめなのは **Cloudflare Web Analytics** です（無制限・Cookie不要）。

1. [Cloudflare Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics) でサイトを追加
2. 発行されたトークンを「アクセス」タブの **ID / トークン** に貼る
3. 公開する

以降、Cloudflare 側で共有ダッシュボードのURLを発行して **ダッシュボードURL** に入れると、
更新ページの中で数字がそのまま見られるようになります。

---

## アフィリエイト（任意）

「プロフィール」タブの一番下でIDを入れます。
入れておくと、「愛用品」に貼った Amazon / 楽天 / Apple のリンクへ自動でIDが付きます。

IDを設定している間は、**景表法（ステマ規制）対応の広告表記が自動で表示されます**。消さないでください。

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 公開を押してもエラーになる | トークンの有効期限切れ。作り直して入れ直す |
| 反映されない | 1〜2分待つ。それでも変わらなければブラウザを再読み込み |
| 間違えて消した | GitHub の `data/` フォルダの履歴から元に戻せます |
| 接続したくない | 「接続設定」の下にある「変更したファイルを書き出す」でJSONを保存し、GitHub の `data/` にドラッグ&ドロップ |
